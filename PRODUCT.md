# Product

## Register

product

## Users

A single power user (the app's own builder) running school, projects, goals, finances,
coding, and fitness through one mobile-first dashboard. Opens it throughout the day —
morning briefing, quick task capture between classes/meetings, voice notes on the go.
The job to be done on any screen is fast triage: what's the one thing that matters right
now, and can I update the system without breaking my flow to do it.

## Product Purpose

Rohtak (formerly Sakai) is an AI-powered personal chief of staff: a life dashboard that
ingests school, work, coding, and personal signals (Gmail, Calendar, GitHub, Canvas) and
turns them into a single prioritized view with an explanation for every priority. Chat is
the primary input — natural language in, structured dashboard state out — not a bolted-on
assistant tab. Success looks like: open the app, know the one right next action in under
three seconds, trust the "why."

## Brand Personality

Calm, warm, considered. Unhurried but not slow — confident triage, not urgency theater.
Claude-inspired: cream/ink/coral, serif display type paired with a clean system sans,
generous whitespace over dense data. The personal touches (cherry blossom in light mode,
constellation in dark mode) exist because this is a tool for one person's whole life, not
a faceless SaaS product — restraint everywhere except that one signature decorative touch.

## Anti-references

Not a generic SaaS dashboard: no blue/purple gradients, no hero-metric-card template, no
identical icon+heading+text grids, no tiny uppercase tracked eyebrows over every section.
Not gamified: no streaks, badges, confetti, mascots. Not a cold enterprise/admin tool: no
dense data-grids, no clinical spacing, no navy-and-gray corporate palette.

## Design Principles

- **One right action, not a list of options.** Every screen should make it obvious what to
  do next before it shows everything else there is to do.
- **Explain, don't just categorize.** A priority without a "why" is just an unexplained
  sort order — the reasoning is the product's value, not decoration.
- **Chat is the front door.** Typing/speaking an update should feel at least as fast as
  navigating to the right screen and filling a form.
- **Warmth through restraint.** One considered decorative signature (seasonal/ambient,
  theme-aware) beats scattered ornamentation — most of the UI stays quiet so that one touch
  reads as intentional.
- **Personal, not enterprise.** Every design decision should read as "built for one life,"
  not "built for a team's admin panel."

## Accessibility & Inclusion

Standard WCAG AA (contrast, focus states, tap targets ≥44px for mobile). All ambient/
decorative motion (constellation drift, cherry blossom fall) must respect
`prefers-reduced-motion` with a static fallback — these are enhancement, never load-bearing
for comprehension.
